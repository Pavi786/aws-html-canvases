Stage 02
How the Internet Actually Works
Networking is the skeleton of everything — every attack travels over a network
Weeks 2–5
✓
📦The OSI Model — 7 Layers
How data gets from your computer to a website and back — attackers exploit specific layers
Simple Analogy
Sending a letter: You write it (Layer 7), seal it (Layer 6), address it (Layer 5–4), hand it to the post office (Layer 3–2), who loads it on a truck (Layer 1).
7 Layers to Memorise
Layer 7 Application — Chrome, WhatsApp, email clients
Layer 6 Presentation — encryption/decryption (HTTPS)
Layer 5 Session — keeps the conversation alive
Layer 4 Transport — TCP (reliable) vs UDP (fast)
Layer 3 Network — IP addresses, routing
Layer 2 Data Link — MAC addresses, switches
Layer 1 Physical — cables, Wi-Fi radio waves
Memory Trick
"Please Do Not Throw Sausage Pizza Away" = Physical → Application
✓
📮IP Addresses & Subnetting
Every device has an address — you need to read, calculate and interpret them instantly
Simple Analogy
IPs are house addresses. 192.168.1.5 = House 5, Street 1, District 168. The /24 tells you the neighbourhood size (254 houses).
Must Know
Private IPs (your home/office): 192.168.x.x, 10.x.x.x, 172.16–31.x.x
/24 = 254 usable IPs · /16 = 65,534 IPs · /32 = just 1 IP
Public IP = what the internet sees (your building's front door)
Practice
subnettingpractice.comTryHackMe: Pre-Security
✓
🗣️Protocols & Port Numbers
The "languages" computers speak — and which door number each lives on
Simple Analogy
Ports are apartment numbers. The IP is the building. HTTP lives in apartment 80, HTTPS in 443, SSH in 22. Knowing this lets you identify what's on a server instantly.
Critical Ports
22 SSH — secure remote login · 80 HTTP — unencrypted web
443 HTTPS — encrypted web (the padlock 🔒)
21 FTP — file transfer, often misconfigured & easy to exploit
445 SMB — Windows file sharing · famous target of WannaCry
53 DNS — the internet's phonebook (names → IP addresses)
3389 RDP — Windows Remote Desktop · attackers love finding this open
✓
🔬Wireshark — See Real Traffic
An X-ray machine for your network — see every packet flying in real time
Simple Analogy
Reading every letter delivered in your neighbourhood. If they forgot to seal the envelope (no encryption), you can read the message inside. This is literally what happens on unencrypted networks.
Practice Tasks
Capture traffic while browsing — spot DNS queries and HTTP responses live
Filter by protocol: type "http" or "dns" in the filter bar
Download PCAP files from malware-traffic-analysis.net — analyse real attack traffic
Find login credentials in a plain FTP session — completely eye-opening
Tools
WiresharktcpdumpNetworkMiner

Stage 03
Linux & Coding — Your Core Weapons
The terminal, Bash scripts, and Python are how hackers get things done fast
Weeks 3–7
✓
⌨️Master the Linux Terminal
Stop using the mouse — the terminal is 10× faster and the only option on remote servers
Simple Analogy
Texting your computer instead of calling it. You type instructions directly. It's faster, scriptable, and works even when there's no graphical interface — which is every server you'll ever hack.
Commands to Master
ls -la → show ALL files including hidden ones
grep "password" file.txt → search for a word inside a file
find / -name "*.conf" → find all config files system-wide
chmod 777 file → give everyone full permissions
cat /etc/passwd → see all user accounts on the system
netstat -ano → see all active network connections
Best Challenge
Complete all 33 levels of OverTheWire Bandit — pure Linux puzzles, the fastest way to get comfortable in any terminal
✓
📜Bash Scripting
Write small programs that automate repetitive tasks — hackers automate everything
Simple Analogy
Like Excel macros for your terminal. Instead of running 100 commands by hand, write them once in a script and run it with one keystroke.
Build These 4 Scripts
Ping sweeper — auto-check which IPs in a subnet are online
Log parser — scan auth.log and list all failed SSH attempts
File backup — compress a folder with a timestamp, automatically
Port checker — test if a port is open on a given IP
✓
🐍Python for Hacking
The #1 cybersecurity language — build tools, write exploits, automate attacks
Simple Analogy
Python is LEGO for hackers. A few blocks = a port scanner. A few more = a brute-force login tool. Every professional tool you'll use can be extended with Python.
Key Libraries
socket — raw network connections, build your own scanner
requests — interact with websites, automate logins
subprocess — run system commands from inside Python
hashlib — generate and crack password hashes
Projects to Build
TCP port scanner in under 20 lines
Password hash cracker using rockyou.txt wordlist
Resources

Stage 04
Offensive Security — Start Hacking Legally
Attack systems in your lab and on CTF platforms — controlled, safe, educational
Months 2–5
✓
🔍Reconnaissance with Nmap
The first step of every hack — find out what's running before you try to break in
Simple Analogy
Knocking on every door in a building. Nmap finds which doors (ports) are open, what's behind them (services), and who lives there (OS version) — before you try to break in.
Core Commands
nmap -sV -sC -oN out.txt [IP] — version scan + scripts + save results
nmap -p- [IP] — scan ALL 65,535 ports, not just the common 1000
nmap -A [IP] — OS detection + traceroute + all default scripts
Tools
NmapRustscanMasscan

The 10 most common ways websites get hacked — know all of them
Simple Analogy
OWASP is the "Most Wanted" list for web vulnerabilities. Master these 10 and you can test 80% of all web apps professionally.
Top 3 to Master First
SQL Injection — trick a login form into dumping the entire database
XSS — inject JavaScript into a site that runs in other users' browsers to steal cookies
File Upload — upload a PHP web shell disguised as an image

💥Metasploit Framework
2,000+ ready-made exploits for known vulnerabilities — the Swiss Army knife of hacking
Simple Analogy
A master key ring with 2,000 keys. Search for the key that fits the lock (vulnerability), insert it, and you're in. Each key is an exploit for a known software flaw.
Basic Attack Flow

5. run → get a shell on the target machine

🪜Privilege Escalation
You landed as a normal user — now climb to root/admin using misconfigurations
Simple Analogy
Upgrading a visitor pass to a master key. You start with limited access, find a loophole in how the system was configured, and exploit it to get full administrator control.
Common Linux Techniques
SUID binaries — files that run as root even when a normal user executes them
sudo -l — find commands you're allowed to run as root without a password
Writable cron jobs — if root runs a script you can edit, inject your own commands

🏰Active Directory Attacks
95% of companies run AD — own it and you own the entire organisation
Simple Analogy
AD is a company's ID card system. It controls who accesses what. Hack the AD server and you can impersonate anyone, open any door, and read every file in the company.
Key Techniques
Kerberoasting — steal encrypted tickets for service accounts and crack them offline
Pass-the-Hash — reuse a stolen password hash without knowing the real password
BloodHound — visually maps the shortest path to becoming Domain Admin
DCSync — trick the domain controller into handing you ALL password hashes

Spot attacks in real time, respond to breaches, and investigate what happened

📊SIEM & Log Analysis
Monitor thousands of logs and spot the one packet that means you're being hacked
Simple Analogy
A security camera system for your entire network. Every device sends its activity logs to one place. You watch for patterns that mean "attack happening right now."
Red Flags to Learn to Spot
100 failed logins in 60 seconds = brute force attack
New admin account created at 3am = likely breach
Data sent to an unknown foreign IP = exfiltration in progress
Tools

✓
🚨Incident Response
The fire drill for when a hack happens — stop it, fix it, learn from it
Simple Analogy
A paramedic for hacked systems. Someone got breached. You arrive, stop the bleeding, figure out how it happened, remove the attacker, fix the damage, write the report.
The 6 Steps (PICERL)
1 Preparation — have a plan before the attack
2 Identification — confirm it's a real attack (not a false alarm)
3 Containment — isolate infected systems, stop the spread
4 Eradication — remove malware, close the backdoor, patch the hole
5 Recovery — bring systems back online safely
6 Lessons Learned — write report so it never happens the same way again
✓
🔬Digital Forensics
Detective work on computers — recover deleted evidence, trace attacker steps
Simple Analogy
CSI for computers. The attacker deleted their tracks. You find them anyway. Using forensic tools you reconstruct exactly what happened — minute by minute.
Key Skills
Memory forensics — analyse a RAM dump to find running malware and decrypted passwords
Disk forensics — recover deleted files, browser history, timeline of events
Log analysis — trace the attacker's every move from the log trail they left
Tools
Volatility 3AutopsyFTK Imager
✓
🦠Malware Analysis
Dissect viruses and ransomware in a safe sandbox to understand what they do
Simple Analogy
A bomb disposal expert studying an unexploded bomb. You take it apart carefully in a sealed environment to understand how it works and how to neutralise it.
Two Types
Static — examine without running it: check strings, file type, imports
Dynamic — run it in a sandbox and watch: what files? what network connections?

Stage 06
Cloud, Mobile & Advanced Surfaces
The modern attack surface has moved to the cloud — learn to attack and defend it
Months 8–12
✓
☁️Cloud Security (AWS / Azure)
Misconfigured cloud = open vault. The #1 cause of major data breaches today
Simple Analogy
Storing your valuables in an invisible safe. If you misconfigure it (forget to lock it), anyone on the internet can walk in. This happens every single day at major companies.
Most Common Misconfigurations
Public S3 bucket — a storage folder accessible to the entire internet by accident
Over-permissive IAM — one compromised account can access everything
SSRF → metadata credentials — trick a server into handing you its own master keys
Free Practice
flaws.cloudCloudGoatAWS Free Tier
✓
📱Mobile Security
Your phone holds your bank, location, emails — apps are full of security holes
Simple Analogy
Apps often leave their back door unlocked. They store passwords in plain text, trust the user's device too much, or send data unencrypted. You intercept traffic and find these flaws.
Key Skills
Intercept app traffic with Burp Suite — even HTTPS with SSL pinning bypass
Decompile APKs with jadx to read the app's source code
Use Frida to hook into live apps and modify behaviour in real time
Tools
FridaMobSFAPKTooljadx

⚙️Reverse Engineering
Take apart compiled software and understand what it does — without the source code
Simple Analogy
Reading a shredded instruction manual. Software is turned into machine code (1s and 0s). RE tools reconstruct it into something human-readable so you can understand what it does — essential for malware analysis.
Start With
Learn just enough x86 Assembly to read what Ghidra shows you
Decompile a simple malware sample in Ghidra
Solve crackme challenges on crackmes.one

🔬Security Research & CVEs
Discover new vulnerabilities nobody has found before — and get your name on them
Simple Analogy

How to Find Your First CVE
Pick a popular open-source project on GitHub
Test its web interface with Burp Suite for OWASP vulnerabilities
Report to the vendor privately (responsible disclosure)
They issue a CVE with your name if confirmed — done
