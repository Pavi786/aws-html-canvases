Compute Services

🖥️ Virtual Machines (VMs) IaaS
Layman Way

Like renting a fully equipped computer inside Microsoft's data center. You pick the size, choose the OS (Windows or Linux), and have full control — install any software, run any workload. It's your computer, hosted in the cloud.

Pro Architecture

Azure VMs are IaaS. You manage: OS, runtime, middleware, application, data. Azure manages: hardware, physical host, networking fabric, storage backend.

Availability Set: Protects against hardware failures in SAME datacenter. Fault domains (rack) + Update domains (patch groups). SLA 99.95%.
Availability Zone: Protects against ENTIRE datacenter failure. Physically separate buildings. SLA 99.99%.
VMSS (Scale Set): Auto-scale identical VMs based on metrics. Supports Availability Zones + Spot VMs + Load Balancer.
Rule: For max HA → Availability Zones. For same-AZ redundancy → Availability Sets. For auto-scaling → VMSS.

✅ DO's
  • Always deploy across multiple Availability Zones
  • Use Managed Disks (not unmanaged) for OS/data disks
  • Enable Azure Backup for all production VMs
  • Use VMSS for any auto-scaling requirement
  • Apply Azure Hybrid Benefit if you have Windows licenses
  • Use Bastion instead of public IP for SSH/RDP access
  • Tag every VM with environment/team/project for cost tracking
❌ DON'Ts
  • NEVER expose port 22 (SSH) or 3389 (RDP) to 0.0.0.0/0
  • NEVER put VMs in a single Availability Set/Zone for prod
  • AVOID storing data on OS disk (use data disks or Blob)
  • AVOID paying On-Demand for VMs running 24/7 (use Reserved)
  • NEVER leave unused VMs running (stop=deallocate to save cost)
  • AVOID using unmanaged disks (deprecated)
  • NEVER ignore VM patch status (enable auto-patching)
💰 VM COST BREAKDOWN — Standard_D4s_v3 (4 vCPU, 16GB RAM, East US)
  • Pay-As-You-Go: ~$0.192/hour = ~$140/month
  • 1-Year Reserved: ~$0.108/hour = ~$79/month (44% savings)
  • 3-Year Reserved: ~$0.072/hour = ~$53/month (63% savings)
  • Spot VM: ~$0.036/hour = ~$26/month (81% savings!) — but can be evicted
  • Azure Hybrid Benefit: Save 40% more if you own Windows Server licenses

⚠️ Pro Tip: Deallocate (not just Stop) VMs when not needed. 'Stopped' VM still charges for compute!

λ Azure Functions Serverless
Layman Way

Like hiring a worker who only shows up when there's work to do. You write a small piece of code, upload it, and Azure handles everything — servers, scaling, OS, runtime. You pay ONLY for the exact milliseconds your code runs.

Pro Architecture

Triggers: HTTP, Timer, Blob upload, Queue, Event Hub, Service Bus, CosmosDB change.
Bindings: Declarative connections — no boilerplate code. Durable Functions: Stateful workflows with orchestrator + activity functions.

5 Common Azure Functions Patterns:
1. Image Processing: Blob upload → resize/watermark → output Blob + Cosmos DB metadata
2. Scheduled Report: Timer → query SQL → generate Excel → email via SendGrid
3. Event-Driven Microservice: Service Bus → process order → write Cosmos DB → publish to Event Hub
4. API Backend: HTTP → validate JWT → read SQL → return JSON
5. Durable Workflow: Order → send approval email → WAIT days → continue processing

🐳 AKS — Azure Kubernetes Service Orchestration
Layman Way

Like a sophisticated shipping port manager. Ships (containers) arrive, the port manager decides which dock (node) each ship goes to, makes sure the right number of ships are always at port, and replaces broken ships automatically.

Pro Architecture

AKS control plane is managed by Azure (FREE). You pay only for node VMs. Supports Spot node pools (up to 90% cheaper), Azure CNI for VNet-native IPs, and KEDA for event-driven pod scaling.

Storage Services

🗄️ Azure Blob Storage Object Storage
Layman Way

A massive, infinitely scalable hard drive in the cloud. 'Blob' = Binary Large Object. Store anything: images, videos, backups, log files, ML models, app artifacts, static website files. Fractions of a penny per GB, scales to petabytes.

Blob Types

Block Blobs: Files/data — 99% of use cases.
Page Blobs: VM disks, random read/write.
Append Blobs: Logs — append-only operations.

Access TierAccess PatternStorage CostAccess CostRetrieval

CoolInfrequently accessed (30+ days)$0.01/GB/month (44% cheaper)$0.01/10,000 readsMilliseconds

ArchiveLong-term archive (180+ days)$0.00099/GB/month (94% cheaper)$5/10,000 readsHours (rehydrate first)

Lifecycle Management — Auto-Tiering: Create rules to automatically move blobs between tiers based on age.
Example Rule: Move to Cool after 30 days → Cold after 90 days → Archive after 365 days → Delete after 7 years.
Business Impact: 1TB of logs/day: ~$18/day in Hot → $0.18/day in Archive after 1 year. 99% cost reduction!

Networking Services

🏙️ Azure Virtual Network (VNet) Core Networking
Layman Way

Like building your own private city inside Azure. You decide the streets (subnets), the neighborhoods (IP ranges), the gated communities (NSGs), the highways to other cities (VNet peering), and the tunnels to your home office (VPN/ExpressRoute).

Hub-Spoke Architecture

Hub VNet: Shared services — Azure Firewall, VPN Gateway, ExpressRoute, Bastion, DNS.
Spoke VNets: One per app/team/environment. Peered to Hub.
⚠️ VNet Peering is NOT transitive.

Database Services

🔵 Azure SQL Database Managed Relational
Layman Way

Like hiring a world-class DBA who works 24/7 for you. They install SQL Server, patch it, back it up every 5-12 minutes, replicate it to another region for disaster recovery, auto-tune queries, and scale as needed.

Deployment Options

Single Database: Own resources, own billing. Full SQL Server feature set.
Elastic Pool: Shared DTU/vCore pool — cost-efficient for SaaS.
SQL Managed Instance: Near 100% SQL Server compatibility. VNet injection.
SQL Server on VM: Maximum control.

ModelTierBest ForKey Characteristic
vCore-basedGeneral PurposeBalanced production workloadsSeparate compute/storage billing. Azure Hybrid Benefit eligible
vCore-basedBusiness CriticalMission-critical, low latencyLocal SSD storage, 3 HA replicas, 1 free readable secondary
vCore-basedHyperscaleMassive scale (100TB+), large OLTPDistributed architecture, 100TB+, fast backups, read from secondary
ServerlessGeneral Purpose onlyUnpredictable/intermittent usageAuto-pause after inactivity. Auto-scale 0.5–40 vCores. Pay per second

Failover Groups: Auto-failover to secondary region. One connection string (listener endpoint) always points to primary. RPO ~5 sec, RTO ~30 sec.
Point-in-Time Restore: Restore to ANY second in retention period (7-35 days). Saves you from accidental deletes.
Always Encrypted: Client-side encryption. Even DBAs cannot see sensitive data. For PII/financial data.

🌌 Azure Cosmos DB NoSQL · Global
Layman Way

A magical database that exists simultaneously in every city in the world. A user in Tokyo reads from Tokyo. A user in New York writes in New York. Both see each other's changes within milliseconds. Scales to millions of operations/second automatically.

Pro Architecture

Partition Key: CRITICAL design decision. High cardinality = even spread = best performance. Wrong key = hot partition = throttling.
Request Units (RU/s): Currency of Cosmos DB. 1 RU = 1 KB read. Writes cost more (~5 RU).

Consistency LevelGuaranteeLatencyUse Case
StrongAlways reads latest write. No stalenessHighest (waits for all regions)Financial transactions, inventory systems
Bounded StalenessData max K versions or T seconds oldHighLeader boards, gaming scores
SessionConsistent for YOUR session (reads your writes)ModerateShopping carts, user profiles — most common
Consistent PrefixNo out-of-order reads, but can be staleLowSocial media feeds, comment threads
EventualMaximum performance, eventual convergenceLowestLike/view counters, non-critical metrics
💰 COSMOS DB COST MODEL
  • Provisioned Throughput: Pay for RU/s reserved 24/7. Minimum 400 RU/s per container = ~$23/month
  • Autoscale: Set max RU/s, Cosmos scales between 10% and 100% automatically
  • Serverless: Pay per actual RU consumed. No minimum. Perfect for dev/test or very bursty workloads
  • Storage: $0.25/GB/month regardless of tier

⚠️ Common Cost Trap: Each container needs minimum RU/s. 100 containers × 400 RU/s = $2,300/month minimum! Use shared throughput at database level.

🔑 Azure Key Vault Secrets Management
Layman Way

Your bank's safe deposit box in the cloud. Store three types: Secrets (passwords, connection strings, API keys), Keys (cryptographic keys), and Certificates (SSL/TLS certs). Apps access them via API without anyone ever seeing raw values. Not even Microsoft can read what's in your vault.

Pro Best Practices

Use RBAC (not Access Policies). Enable Purge Protection and Soft Delete. Use Private Endpoints for compliance. Reference secrets in App Service via Key Vault References — no code changes needed.

Security & Identity

👤 Microsoft Entra ID formerly Azure AD
Layman Way

The bouncer and membership card system for everything Microsoft. Decides if you can log in to Office 365, Azure Portal, your company's custom apps. It's MFA, conditional access, single sign-on, and much more.

Managed Identity — Critical Concept

System-Assigned: Tied to ONE resource. Dies with the resource. Simple for single-resource scenarios.
User-Assigned: Standalone resource. Assign to MULTIPLE resources. Persist independently.
Rule: 1 app = System-Assigned. Shared = User-Assigned.

Entra ID ConceptAnalogyTechnical Detail
Managed IdentityRobot with auto-renewing badgeAzure-managed service principal. No password to rotate. Best for Azure-to-Azure auth
RBAC RoleJob title with specific clearancesAzure RBAC: Owner, Contributor, Reader, or custom. Assigned at subscription/RG/resource scope
Conditional AccessSmart security checkpointRequire MFA if logging in from new country. Block if device non-compliant. Allow only from corporate IPs
MFA / PasswordlessTwo-factor ID checkSMS, Authenticator app, FIDO2 key, Windows Hello. Blocks 99.9% of credential attacks
PIMTemporary promotion to VIP accessJust-in-time privileged access. Approve, time-limit, and audit elevated role assignments
🛡️ Defender for Cloud + Microsoft Sentinel CSPM · SIEM · SOAR
Defender for Cloud

Continuously scans your entire Azure environment and gives it a Secure Score (0-100%). Detects active attacks in real-time. Covers servers, SQL, storage, containers, App Service, Key Vault, DNS, Resource Manager.

Microsoft Sentinel

AI-powered SIEM + SOAR. Ingests logs from everything (Azure, AWS, GCP, 300+ connectors). Uses AI to detect threats. Automates responses — block IP, disable user, notify team — before you even wake up.

☁️ Where Azure Wins
  • Enterprise Microsoft Integration: Office 365, Teams, Active Directory, Exchange
  • Hybrid Cloud: Azure Arc extends management to on-prem, other clouds
  • Windows Workloads: Better Windows VM licensing (Hybrid Benefit), SQL Server integration, .NET
  • Identity (Entra ID): Most enterprises already use Azure AD. Seamless for enterprise apps
  • Compliance: 90+ compliance certifications. Strong in EU, government, healthcare
  • AI/Copilot Integration: OpenAI partnership. Exclusive enterprise GPT-4 access
  • Cosmos DB Multi-API: SQL, MongoDB, Cassandra, Gremlin, Table APIs — AWS has no equivalent
⚡ Where AWS Wins
  • Market Share & Maturity: 32% vs Azure 22%. More services, more mature, longer track record
  • Service Breadth: 200+ services vs ~100+. AWS has niche services Azure doesn't
  • Spot Instance Reliability: AWS Spot more predictable interruption patterns
  • Global Reach: More regions, more CloudFront PoPs, lower latency in more countries
  • DynamoDB: Simpler pricing, more mature than Cosmos DB
  • Serverless Maturity: Lambda has more triggers, better tooling, larger community
  • Open Source Community: AWS contributes more to open source tools
