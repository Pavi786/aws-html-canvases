🤝 The Layman Analogy: The Land Registry

Think of GoDaddy as the City's Land Registry Office. You visit them to buy a "Street Name" (Domain). Once you have the name, you decide which "Map Maker" (Nameserver) will tell people where your house is. Locking your domain is like putting a physical padlock on your property deed so nobody can steal it while you're sleeping.

Pro Workflow: Nameserver Delegation

Scenario: You bought a domain on GoDaddy, but you want Cloudflare to handle the traffic. Here is the actual sequence:

1

Add Domain to Cloudflare

Cloudflare will scan your GoDaddy records and give you two nameservers (e.g., becky.ns.cloudflare.com).

2

Update GoDaddy DNS Management

In GoDaddy, find "Nameservers" -> "Change" -> "Enter my own." Delete GoDaddy's defaults and paste Cloudflare's.

3

Wait for Propagation

The "Internet Library" needs to update its index. This can take 5 minutes or 24 hours.

WHOIS & Privacy

By default, your name, phone, and address are public. DevOps always enables "Privacy Protection" to mask this data.

# Check domain status
whois example.com | grep "Registrar Status"

Glue Records

Used when you want your nameserver to be ns1.yourdomain.com. You must register the IP at the registry level.

The DNS Record Library

A & AAAA (The Coordinates)

A = IPv4 (1.2.3.4), AAAA = IPv6. Directs traffic to a server.

Actual Example

example.com. 3600 IN A 104.21.12.34
MX (The Post Office)

Mail Exchange. Points to your email provider (Google, Outlook).

Actual Example

IN MX 10 aspmx.l.google.com.
SRV (Service Finder)

Tells apps which PORT a service is on (e.g., Minecraft, VoIP).

Actual Example

_minecraft._tcp.srv IN SRV 5 0 25565 mc.host.com
NS (The Delegate)

Delegates a subdomain to a different provider.

Actual Example

dev.example.com. IN NS ns-aws-1.com.

Understanding TTL (Time To Live)

TTL is the "expiration date" of a DNS record in a resolver's cache. High TTL = Faster loading, but hard to change. Low TTL = Fast changes, but more DNS traffic.

🔐 The Layman Analogy: The Bank Vault

A Public Key is like a padlock you hand out to everyone. Anyone can put a letter in a box and snap your padlock shut. But ONLY YOU have the Private Key to open that padlock. CSR is like you filling out an application to the "Department of IDs" asking them to verify you are who you say you are.

Pro Workflow: CSR & SSL Issuance

1

Generate Key & CSR (OpenSSL)

Run this command on your server to create the padlock and the ID application.

openssl req -new -newkey rsa:2048 -nodes -keyout private.key -out request.csr
2

Submit to CA (GoDaddy)

Paste the contents of request.csr into GoDaddy's SSL portal. GoDaddy verifies you own the domain via DNS or Email.

3

Install the CRT

Download the .crt bundle and install it on your platform.

NGINX / Apache Installation
# NGINX Configuration
server {
  listen 443 ssl;
  ssl_certificate /path/to/cert.crt;
  ssl_certificate_key /path/to/private.key;
}
AWS ALB / Kubernetes

In Cloud platforms, you don't edit files. You upload the cert to AWS ACM or create a K8s Secret.

# K8s Secret Command
kubectl create secret tls cert-secret \
  --cert=path/to/cert.crt \
  --key=path/to/private.key

The Email Notary Protocol

SPF (Who sends?)

A list of IP addresses allowed to send mail on your behalf.

v=spf1 include:_spf.google.com ~all

DKIM (Wax Seal)

A cryptographic signature added to every outgoing email header.

v=DKIM1; k=rsa; p=MIIBIjAN...

DMARC (The Law)

Instructions on what to do if SPF or DKIM fails.

v=DMARC1; p=reject;

Scenario: Google Workspace Setup

  1. 1. Add MX records pointing to Google's servers.
  2. 2. Add SPF record: v=spf1 include:_spf.google.com ~all.
  3. 3. Generate DKIM key in Google Admin Console and paste as a TXT record in DNS.
  4. 4. Add DMARC TXT record to start receiving failure reports.

User sees your server's IP directly. WAF and DDoS protection are BYPASSED.

Critical Workflow: SSL Strictness

Flexible SSL

User ↔ Cloudflare (HTTPS), Cloudflare ↔ Origin (HTTP). ⚠️ Unsafe.

Full SSL

Encrypted end-to-end, but doesn't check the Origin certificate's validity.

Full (Strict) ✅

Encrypted end-to-end with a valid CA certificate on the Origin.

Pro Scenario: Restricting Origin IPs

Once Cloudflare is active, you must block all traffic on your NGINX firewall except from Cloudflare's IP ranges.

# NGINX snippet to allow only Cloudflare
allow 173.245.48.0/20;
allow 103.21.244.0/22;
deny all;
