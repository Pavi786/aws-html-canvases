STAGE 02
How the Internet Actually Works
Networking is the skeleton of everything — attacks travel through networks
Weeks 2–5
✓
📦 The OSI Model (7 Layers)
How data gets from your computer to a website and back
Think of it like sending a letter: You write it (Layer 7 - App), put it in an envelope (Layer 6), address it (Layer 5-4), hand it to the post office (Layer 3-2), who puts it on a truck (Layer 1 - Physical).
7 Layers (Memorize This)
Layer 7 — Application: What you use (Chrome, WhatsApp)
Layer 6 — Presentation: Encryption/decryption (HTTPS)
Layer 5 — Session: Keeping the connection alive
Layer 4 — Transport: TCP/UDP — reliable or fast delivery
Layer 3 — Network: IP addresses — WHERE to send it
Layer 2 — Data Link: MAC addresses — HOW to deliver on local network
Layer 1 — Physical: Actual cables, Wi-Fi signals, electricity
Memory Trick
"Please Do Not Throw Sausage Pizza Away" = P(hysical) D(ata Link) N(etwork) T(ransport) S(ession) P(resentation) A(pplication)
✓
📮 IP Addresses & Subnetting
Every device has an address — learn how to read them
Think of IP addresses like house addresses: 192.168.1.5 = House 5, Street 1, District 168, City 192. The /24 tells you how big the neighbourhood is (254 houses).
Key Concepts
Private IPs (your home): 192.168.x.x, 10.x.x.x, 172.16.x.x
Public IP: What the world sees when you browse (like your building's front door)
/24 = 254 usable IPs (most home/office networks)
/32 = just 1 IP (a single host), /8 = 16 million IPs (huge)
Practice Here
subnettingpractice.com TryHackMe: Pre-Security
✓
🗣️ Protocols & Port Numbers
The "languages" computers speak — and their door numbers
Ports are like apartment numbers: The IP is the building, the port is which apartment. HTTP always lives in apartment 80, HTTPS in 443, SSH in 22.
Must-Know Ports
Port 22 = SSH (remote login — like TeamViewer but for nerds)
Port 80 = HTTP (websites without encryption)
Port 443 = HTTPS (websites WITH encryption — the padlock 🔒)
Port 21 = FTP (old-school file transfer — often poorly secured)
Port 445 = SMB (Windows file sharing — target of WannaCry ransomware)
Port 53 = DNS (the internet's phonebook — translates names to IPs)
Port 3389 = RDP (Remote Desktop — hackers love finding this open)
✓
🔬 Wireshark — See Real Network Traffic
Like an X-ray machine that shows you every packet flying through your network
Think of Wireshark like: Reading all the letters being delivered in your neighbourhood. You can see WHO is talking to WHO, and if they forgot to seal their envelope (no encryption), you can read the message inside.
Practice Tasks
Capture traffic while browsing a website — spot DNS queries and HTTP responses
Use filter "http" to find unencrypted web requests
Download PCAP files from malware-traffic-analysis.net and analyze attack traffic
Find login credentials in a plain FTP capture (eye-opening!)
Tools
Wireshark tcpdump NetworkMiner

⌨️ Master the Linux Terminal
Stop using the mouse. The terminal is faster, more powerful, and the only option when you're hacked into a server
Think of the terminal like texting your computer: Instead of clicking icons, you type instructions directly. It's faster AND it works even when there's no graphical interface (which is most servers).
Commands You MUST Know
ls -la → show ALL files including hidden ones (like dir in Windows)
grep "password" file.txt → search for the word "password" inside a file
find / -name "*.conf" → find ALL config files on the whole system
chmod 777 file → give everyone full permission on a file
cat /etc/passwd → see all user accounts on a Linux system
ps aux → see every process running on the machine
netstat -ano → see all open network connections
Best Practice Challenge
Complete ALL 33 levels of OverTheWire Bandit — pure Linux terminal puzzles. This single challenge will make you comfortable in any terminal.
✓
📜 Bash Scripting
Write little programs that automate boring repeated tasks
Bash scripts are like macros in Excel: Instead of manually running 100 commands, you write them once in a script and run it in one click. Hackers automate everything.
Build These Scripts
Ping sweeper — automatically check which computers in a subnet are online
Log parser — scan auth.log and list all failed SSH login attempts
Directory backup — compress important folders with a timestamp automatically
Port checker — check if a specific port is open on a given IP
✓
🐍 Python for Hacking
The #1 language in cybersecurity — used to build tools, write exploits, and automate attacks
Python is like LEGO for hackers: With a few blocks you can build a port scanner, a brute-force tool, a data parser, or a reverse shell. Every professional tool you'll use can be customized or extended with Python.
Key Libraries to Learn
socket — for making raw network connections (build your own scanner)
requests — for interacting with websites (brute force logins, crawl pages)
subprocess — run system commands from inside your Python script
hashlib — generate and crack password hashes
Build These Projects
TCP port scanner in under 20 lines of Python
Password hash cracker using a wordlist (rockyou.txt)
Simple keylogger (for educational understanding only)

STAGE 04
Offensive Security — Start Hacking Legally
Learn to attack systems so you understand how to defend them
Months 2–5
✓
🔍 Reconnaissance with Nmap
The first step of every hack — figure out what's running on a target
Nmap is like knocking on every door in a building: It finds which doors (ports) are open, what's behind them (services), and sometimes even who lives there (OS version). All before you try to break in.
Core Commands
nmap -sV -sC [IP] → scan for open ports + what software is running + run default scripts
nmap -p- [IP] → scan ALL 65,535 ports (not just the common 1000)
nmap -A [IP] → aggressive mode: OS detection + traceroute + scripts
nmap -oN results.txt [IP] → save your scan to a file (always do this)
✓
💉 Web App Hacking (OWASP Top 10)
Learn the 10 most common ways websites get hacked
OWASP is like the "Most Wanted" list of web vulnerabilities: If you know how to find and exploit these 10, you can test 80% of all web apps professionally.
Top 3 You Must Master First
SQL Injection — trick a login form into spitting out the entire database. Example: type ' OR 1=1-- in a username field
XSS (Cross-Site Scripting) — inject JavaScript into a website that runs in OTHER people's browsers. Used for cookie theft
File Upload — upload a PHP file disguised as an image to get code running on the server
Practice Grounds (All Free)
PortSwigger Academy DVWA (local) Burp Suite
✓
💥 Metasploit Framework
The Swiss Army knife of exploitation — automates known attacks
Metasploit is like a master key ring: It has 2,000+ keys (exploits) for known vulnerabilities in software. You search for the key that fits the lock (vulnerability), insert it, and you're in.
The Basic Attack Flow
1. msfconsole → launch Metasploit
2. search ms17-010 → find the EternalBlue exploit (used by WannaCry)
3. use [module] → select it
4. set RHOSTS [target IP] → tell it the target
5. run → launch the exploit → get a shell on the target machine
Tools
Metasploit msfvenom Meterpreter
✓
🪜 Privilege Escalation (PrivEsc)
You got in as a normal user — now become admin/root
PrivEsc is like sneaking from a visitor pass to a master key: You start with limited access. You find a misconfiguration or weakness that lets you upgrade your own permissions to full administrator.
Common Linux PrivEsc Techniques
SUID binaries — find files that run as root even when a normal user executes them
Sudo misconfigurations — "sudo -l" to find commands you can run as root
Writable cron jobs — if root runs a script you can edit, add your own commands
Key Resources
GTFOBins.github.io LinPEAS WinPEAS
✓
🏰 Active Directory Attacks
How to hack Windows company networks — used in 95% of enterprise orgs
Active Directory is like a company's ID card system: It controls who can access what. Hack the AD server and you can impersonate anyone, unlock any door, and access every system in the company.
Key Attack Techniques
Kerberoasting — request encrypted passwords for service accounts, crack them offline
Pass-the-Hash — steal a password hash and use it WITHOUT knowing the actual password
BloodHound — draws a map showing the shortest path to become Domain Admin
DCSync — trick the domain controller into handing you ALL password hashes
Build This Lab
Windows Server 2019 VM (domain controller) + 2 Windows 10 client VMs = full AD practice lab
Tools
BloodHound Impacket Mimikatz CrackMapExec

STAGE 05
Defensive Security — Protect & Detect
Learn to spot attacks, analyze incidents, and hunt threats
Months 4–7
✓
📊 SIEM & Log Analysis
Read thousands of logs and spot the needle in the haystack
A SIEM is like a security camera system for your entire network: Every device — servers, firewalls, laptops — sends their activity logs to one central place. You monitor them to detect attacks happening in real-time.
What to Learn
What is a log? — timestamped record of events (login, file access, network connection)
What to look for: failed logins in bulk = brute force. New admin account created at 3am = breach
Write detection rules (like email filters, but for attack patterns)
Build an ELK Stack (free) on a VM and forward logs from your Kali machine to it
Tools
Splunk (free tier) ELK Stack Wazuh
✓
🚨 Incident Response (IR)
What to do WHEN (not if) a hack happens — the fire drill for breaches
IR is like being a paramedic for hacked systems: Someone got breached. You get called in. You stop the bleeding, figure out what happened, remove the attacker, fix the damage, and prevent it from happening again.
The 6 IR Steps (PICERL)
1. Preparation — have a plan before the attack (policies, tools, playbooks)
2. Identification — confirm an attack is happening (not a false alarm)
3. Containment — isolate infected systems so the attack doesn't spread
4. Eradication — remove the malware, close the backdoor, patch the hole
5. Recovery — bring systems back online safely
6. Lessons Learned — write a report so it never happens the same way again
✓
🔬 Digital Forensics
Detective work on computers — recover evidence and reconstruct attacks
Digital Forensics is like CSI for computers: Someone deleted files before they left. You recover them. An attacker erased their tracks. You find them anyway. You recreate exactly what happened, minute by minute.
Key Skills
Memory forensics — analyze a RAM dump to find running malware, decrypted passwords, open network connections
Disk forensics — recover deleted files, find browser history, timeline reconstruction
Log analysis — trace the attacker's every move from the log trail they left behind
Tools
Volatility 3 Autopsy FTK Imager Plaso
✓
🦠 Malware Analysis
Dissect viruses and ransomware to understand what they do
Malware analysis is like a bomb disposal expert studying an unexploded bomb: You take it apart carefully in a safe environment to understand how it works, what it was designed to do, and how to neutralize it.
Two Types of Analysis
Static — examine the malware file WITHOUT running it. Check strings, imports, file type, obfuscation
Dynamic — run it inside a sandbox and watch what it does. What files does it create? What network connections?
Safe Tools
any.run (online sandbox) VirusTotal Ghidra (NSA tool) Detect-It-Easy

Cloud & Advanced Attack Surfaces
The modern company lives in the cloud — learn to attack and defend it
Months 8–12
✓
☁️ Cloud Security (AWS/Azure/GCP)
Misconfigured cloud = open vault. The #1 cause of breaches today
Cloud security is like locking your house when it's invisible: Companies store data on AWS/Azure/GCP servers they don't physically own. If you misconfigure them (leave the door unlocked), anyone in the world can walk in. And many do.
Common Cloud Vulnerabilities
Public S3 bucket — a storage folder accidentally made accessible to the entire internet (contains thousands of leaked files every year)
Over-permissive IAM roles — a single compromised user account can access everything because permissions weren't restricted
SSRF to steal cloud credentials — trick a server into fetching its own internal metadata and giving you the master keys
Free Practice Grounds
flaws.cloud CloudGoat AWS Free Tier
✓
📱 Mobile Security
Your phone holds your bank, emails, location — make it your expertise
Mobile security is hacking apps on phones: Apps often store passwords in plain text, send data over unencrypted connections, or trust the user's device too much. You intercept traffic, decompile apps, and find these flaws.
Key Skills
Intercept mobile app traffic with Burp Suite (even HTTPS with SSL pinning bypass)
Decompile APKs to read the app's source code (jadx tool)
Use Frida to hook into running apps and modify their behavior in real-time
Tools
Frida MobSF APKTool jadx
✓
⚙️ Reverse Engineering
Take apart compiled software to understand what it does without source code
Reverse engineering is like reading a shredded manual: Software is compiled into machine code (1s and 0s). RE tools reconstruct it into something human-readable so you can understand what a program does — especially useful for malware analysis and cracking software protections.
Start With
Learn x86 Assembly basics — just enough to read what Ghidra shows you
Use Ghidra (free, NSA-built) to decompile a simple malware sample
Solve "crackme" challenges on crackmes.one — programs that check for a secret password
Tools
Ghidra IDA Free x64dbg crackmes.one

🔴 OSCP (Offensive Gold Standard)
A 24-hour live hacking exam. The most respected pentesting cert in the world
OSCP is a 24-hour exam where you hack real machines: No multiple choice. No theory. You're given 5+ machines and must break into them and document your findings. Pass = you can actually hack. Fail = try again.
Prerequisites (Do First)
Complete TryHackMe "Jr Pentester" path

The MBA of cybersecurity — needed for director-level and CISO roles
CISSP is for experienced professionals moving into leadership: It covers all 8 security domains from a management perspective. Companies pay CISSP holders $130K–$200K+ annually. But you need 5 years of experience to qualify.
When to Pursue
After 5+ years of hands-on experience in 2+ security domains
When you're targeting senior security engineer or management roles

Become Elite & Build Your Name
The best jobs don't get posted — they go to people who are known
Year 2+
✓
💰 Bug Bounty Hunting
Companies PAY you real money to find vulnerabilities in their systems
Bug bounties are like paid treasure hunts: Companies list their apps on platforms like HackerOne. You try to break them. If you find a real vulnerability and report it responsibly, they pay you — sometimes $100, sometimes $100,000+.
How to Start
Create a HackerOne.com or Bugcrowd.com account
Start with programs that have "VDP" (Vulnerability Disclosure Program) — no payout but good practice
Focus on 1 bug class you know well (XSS, SSRF, IDOR) and find it everywhere
Your first report doesn't have to be paid — it proves real-world experience
✓
🔬 Security Research & CVEs
Discover new vulnerabilities nobody has found before
A CVE is like naming a discovered asteroid after yourself: CVE = Common Vulnerabilities and Exposures. When YOU find a new bug in widely-used software, you get a CVE number credited to your name. It lives on your LinkedIn forever and is extremely prestigious.
How to Find Your First CVE
Pick an open-source project on GitHub with many stars
Look for outdated dependencies (npm audit, safety check)
Test the web interface with Burp Suite for OWASP vulnerabilities
Contact the vendor privately with your findings (responsible disclosure)
They'll issue a CVE with your name if it's confirmed valid

Share what you know — this is the fastest way to career growth
Teaching others is the best proof you truly understand something: Write a blog post, speak at BSides, mentor someone on Reddit. The community rewards generosity. The people who share the most get the best job offers.
Actions to Take

🤖 AI & Emerging Threats
The next frontier — AI is changing both attacks and defenses
AI security is the new gold rush: Attackers use AI to write better phishing emails, find vulnerabilities faster, and evade detection. Defenders use AI to detect threats in real-time. Whoever understands both sides will be indispensable.
Emerging Areas to Study
Prompt injection — trick AI assistants into ignoring their safety rules (new field, few experts)
LLM security — find vulnerabilities in AI-powered apps (data leakage, SSRF via AI agents)
AI-powered threat hunting — use ML models to detect anomalies in network traffic
Adversarial machine learning — fool AI image classifiers and malware detectors
