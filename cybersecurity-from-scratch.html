01.1
Understand what cybersecurity actually is
▼
Before you learn any tool, understand the landscape. Cybersecurity protects systems, networks, and data from attacks. Know the difference between offensive (Red Team), defensive (Blue Team), and governance (GRC) paths.
Do This:
Watch "Cybersecurity Career Roadmap" by NetworkChuck on YouTube (free, 20 min)
Read the Wikipedia article on Information Security — just the overview
Decide: Are you drawn to breaking things (offensive) or defending things (defensive)? Both is fine too
YouTube: NetworkChuck TryHackMe.com Reddit: r/cybersecurity
PRO TIP: You don't need to pick a lane yet. But know that the best defenders were offensive, and the best attackers understand defenses deeply.
✓
01.2
Set up your hacking lab (VirtualBox + Kali Linux)
▼
Never hack real systems while learning. Build a safe, isolated lab on your own machine. You need a host OS + virtualization software + attack OS (Kali Linux).
Exact Steps:
Download and install VirtualBox (free) from virtualbox.org
Download Kali Linux ISO from kali.org (the official attacker OS with 600+ pre-installed tools)
Create a new VM in VirtualBox: 4GB RAM, 50GB disk, 2 CPU cores minimum
Install Kali — set up user/password — take a snapshot so you can revert anytime
Also download Metasploitable2 as your target VM (a deliberately vulnerable Linux system)
Set both VMs on a "Host-Only" network so they can talk to each other but NOT the internet
kali.org virtualbox.org YouTube: "Kali Linux VM Setup 2024"
PRO TIP: Snapshots are your save states. Before trying anything risky — snapshot. You'll thank yourself later.

STAGE 02
Master Networking (The Foundation)
Everything in cybersecurity travels over a network — learn how it works
Weeks 2–5
✓
02.1
Learn the OSI & TCP/IP Models
▼
The OSI Model has 7 layers. TCP/IP has 4. Attacks happen at specific layers. You MUST know this. When you hear "Layer 7 attack" you need to immediately know that's the Application layer (HTTP, DNS).
Study:
Memorize all 7 OSI layers and what protocols live at each (use the mnemonic: "Please Do Not Throw Sausage Pizza Away")
Understand how a packet travels from your browser to a server and back
Know the difference between TCP (reliable, 3-way handshake) vs UDP (fast, no guarantee)
Complete TryHackMe room: "Pre-Security → Network Fundamentals"
TryHackMe: Pre-Security Professor Messer YouTube
✓
02.2
Understand IP Addressing & Subnetting
▼
You need to look at an IP like 192.168.1.0/24 and instantly know it's a private subnet with 254 hosts. Subnetting trips up beginners but once it clicks, it clicks forever.
Learn & Practice:
Understand IPv4 vs IPv6, public vs private IPs (10.x.x.x, 192.168.x.x, 172.16.x.x)
Learn CIDR notation: /24 = 256 IPs, /16 = 65536 IPs
Practice subnetting on subnettingpractice.com until you can do it in your head
Understand what a default gateway, DNS server, and DHCP server do
subnettingpractice.com Cisco Networking Academy
✓
02.3
Learn Key Protocols: DNS, HTTP, FTP, SSH, SMTP
▼
Protocols are the language of the internet. Each one has attack vectors you'll exploit later. Know what each one does, what port it runs on, and how it can be abused.
Know These Cold:
DNS (port 53) — translates domains to IPs; attack: DNS poisoning, zone transfer
HTTP (80) / HTTPS (443) — web traffic; attack: MITM, injection, SSRF
SSH (22) — secure remote login; attack: brute force, key mismanagement
FTP (21) — file transfer, often misconfigured for anonymous access
SMB (445) — Windows file sharing; famous for EternalBlue / WannaCry
SMTP (25) / POP3 / IMAP — email; attack: phishing, spoofing
TryHackMe: "How the Web Works" YouTube: David Bombal
✓
02.4
Use Wireshark to capture & analyze real traffic
▼
Wireshark is like an X-ray machine for your network. Seeing packets in real-time makes abstract protocols concrete. This single skill separates juniors from seniors in SOC work.
Hands-On Practice:
Install Wireshark on your host OS (wireshark.org)
Capture traffic while browsing a website — find HTTP vs HTTPS packets
Filter by protocol: type "dns" or "http" in the filter bar
Download and analyze PCAP files from malware-traffic-analysis.net
Find credentials in an unencrypted FTP or Telnet capture
wireshark.org malware-traffic-analysis.net TryHackMe: Wireshark room
PRO TIP: Every time you learn a new attack, go back to Wireshark and look at what the packets look like. This builds a "network fingerprint" memory that's invaluable in incident response.

Own Linux (Your Hacking OS)

✓
03.1
Master the Linux terminal & filesystem
▼
In hacking, you live in the terminal. No GUI safety nets. You must navigate, read, write, execute, and chain commands fluently.
Commands to Master:
Navigation: ls -la, cd, pwd, find, locate, tree
File ops: cat, less, grep, cut, awk, sed, head, tail
Permissions: chmod 777, chown, sudo, su, /etc/passwd, /etc/shadow
Networking: ifconfig, ip a, netstat -ano, ss, ping, traceroute, curl, wget
Processes: ps aux, kill, top, htop, jobs, &, nohup
Compression: tar -xvf, zip, unzip, gzip
OverTheWire: Bandit (start here) TryHackMe: Linux Fundamentals linuxcommand.org
CHALLENGE: Complete all 33 levels of OverTheWire Bandit. It's pure Linux and it will make you dangerous with the terminal.
✓
03.2
Write Bash scripts to automate tasks
▼
Automating repetitive tasks with Bash is a superpower. Port scanners, enumeration scripts, log parsers — you'll write all of these.
Write These Scripts:
A ping sweeper: loop through IPs in a subnet and report which ones respond
A basic port scanner using /dev/tcp bash built-in
A file backup script with timestamps
A log parser that finds all failed SSH login attempts from auth.log
bash-scripting.com YouTube: "Bash Scripting Tutorial" NetworkChuck
✓
03.3
Learn Python for hacking & automation
▼
Python is THE language of cybersecurity. Every tool you'll use has Python bindings. You'll write exploits, parse data, automate attacks, and build tools in Python.
Learn & Build:
Learn basics: variables, loops, functions, file I/O, exceptions (1 week on Python basics)
Learn the socket library — build a TCP port scanner in 20 lines
Learn requests library — automate HTTP interactions, brute force login forms
Learn subprocess — call system commands from Python scripts
Build: a password hash cracker using Python + wordlist
Python.org Official Docs HackInScience.org Book: "Black Hat Python" (key read)
PRO TIP: Don't spend months becoming a Python expert before starting. Learn the minimum, then use Python to solve real problems you encounter while hacking.

STAGE 04

Months 2–5
✓
04.1
Enumeration & Reconnaissance with Nmap
▼
Every attack starts with information gathering. Nmap is the #1 port scanner. You'll use it on every single engagement.
Master These Nmap Commands:
nmap -sV -sC -oN output.txt [target] → service version scan + default scripts, save output
nmap -p- [target] → scan ALL 65535 ports
nmap -sU [target] → UDP scan (slower but critical)
nmap -A [target] → aggressive scan (OS detection + scripts)
Scan your Metasploitable2 VM — document every open port and service version
nmap.org/book TryHackMe: "Nmap" room
✓
04.2
Web Application Attacks (OWASP Top 10)
▼
80% of hacking jobs involve web apps. OWASP Top 10 is the bible. Learn every vulnerability category, how to find it, how to exploit it, and how to fix it.
Practice On:
Set up DVWA (Damn Vulnerable Web App) in your lab — practice all 10 vuln types
SQL Injection: dump a database using SQLi, then use sqlmap to automate it
XSS: steal a cookie using reflected and stored XSS
File Upload: bypass extension filters to upload a PHP web shell
Install Burp Suite Community Edition — intercept every request you make
Complete PortSwigger Web Security Academy (free, world-class labs)
portswigger.net/web-security DVWA (localhost) TryHackMe: OWASP Top 10
CHECKPOINT: You should be able to manually exploit SQLi, XSS, and File Upload before moving on. PortSwigger Academy is genuinely the best free resource for this.
✓
04.3
Metasploit Framework — Your Exploitation Engine
▼
Metasploit automates exploitation. It has 2000+ modules for known vulnerabilities. Understanding Metasploit also teaches you how exploits work under the hood.
Learn the Flow:
Launch msfconsole — learn: search, use, show options, set, run/exploit
Exploit MS08-067 on Metasploitable (a classic Windows vuln) in your lab
Get a Meterpreter shell — run: sysinfo, getuid, hashdump, upload, download
Use msfvenom to create a payload (an .exe that calls back to your machine)
Understand the difference between staged and stageless payloads
TryHackMe: Metasploit room Offensive Security Metasploit Unleashed
✓
04.4
Privilege Escalation (PrivEsc)
▼
You almost never land as root/admin. PrivEsc is how you get there. It's one of the most important skills in CTFs and real pentests.
Master Both Linux & Windows:
Linux: SUID binaries, writable cron jobs, sudo -l misconfigs, writable /etc/passwd
Windows: Unquoted service paths, weak service permissions, AlwaysInstallElevated, DLL hijacking
Use LinPEAS and WinPEAS to automate enumeration of privesc vectors
Complete TryHackMe rooms: "Linux PrivEsc" and "Windows PrivEsc"
Reference GTFOBins.github.io for Linux binary exploitation techniques
GTFOBins.github.io TryHackMe: PrivEsc rooms github.com/carlospolop/PEASS-ng
✓
04.5
Complete your first 10 HackTheBox / TryHackMe machines
▼
Real machines, real flags. This is where theory dies and skill begins. Don't use walkthroughs immediately — struggle first. The struggle is the learning.
Order to Tackle:
Start: TryHackMe "Complete Beginner" learning path (guided)
Then: TryHackMe "Jr Penetration Tester" learning path
Then: HackTheBox "Starting Point" tier 0, 1, 2 machines (very guided)
Then: HackTheBox Easy-rated retired machines (use walkthroughs AFTER you try 30–60 min alone)
Write a writeup for every box you complete — this builds your portfolio
TryHackMe.com HackTheBox.com 0xdf.gitlab.io (writeup examples)
MILESTONE: 10 completed machines = you are officially a beginner pentester. Treat this as your first graduation. 🎓

STAGE 05
Learn Defensive Security
See the world from the defender's seat — detection, response, forensics
Months 4–7
✓
05.1
Set up a SIEM with ELK Stack (Elasticsearch + Kibana)
▼
A SIEM collects and analyzes logs from across your environment to find threats. ELK Stack is free and industry-standard. Running one yourself makes SOC work click.
Build This Lab:
Spin up an Ubuntu VM — install Elasticsearch + Logstash + Kibana (the ELK stack)
Forward your Kali Linux logs to the SIEM using Filebeat
Create a dashboard showing: failed logins, new processes, network connections
Run a Nmap scan from Kali → see it show up in Kibana as an alert
elastic.co/start TryHackMe: SOC Level 1 path CyberDefenders.org
✓
05.2
Digital Forensics & Incident Response (DFIR)
▼
When a breach happens, DFIR analysts figure out what happened, how, and what to do. This is one of the highest-paid specializations in cybersecurity.
Learn & Practice:
Memory Forensics: Use Volatility 3 to analyze Windows memory dumps — find injected processes, network connections
Disk Forensics: Use Autopsy to examine disk images — find deleted files, browser history, artifacts
Practice on CyberDefenders "Blue Team Labs" — solve pre-built IR challenges
Learn the Incident Response phases: Preparation, Identification, Containment, Eradication, Recovery, Lessons Learned (PICERL)
volatilityfoundation.org sleuthkit.org (Autopsy) CyberDefenders.org
✓
05.3
Malware Analysis — Static & Dynamic
▼
Reverse engineer malware to understand what it does. This is the forensic autopsy of the attacker's weapon.
Start With:
Static analysis: Use strings, file, PEiD, Detect-It-Easy to analyze a malware sample without running it
Dynamic analysis: Run malware in an isolated Flare-VM sandbox — monitor registry, file, and network changes with Procmon/Wireshark
Upload samples to any.run or VirusTotal sandbox — observe behavior
Start learning Ghidra (free NSA tool) for reverse engineering — disassemble simple malware
any.run sandbox ghidra-sre.org (NSA tool) TryHackMe: Malware Analysis rooms
SAFETY: NEVER run malware on your host machine. Use an isolated VM with no network access or a dedicated sandbox service like any.run.

STAGE 06
Get Certified & Get Hired

✓
06.1
Pass CompTIA Security+ (First Cert)
▼
Security+ is the industry-standard entry cert. It's required for DoD jobs in the US and respected globally. It proves you understand core security concepts across all domains.
Study Plan (6-8 weeks):
Get Professor Messer's free Security+ study guide + videos (professormesser.com)
Buy Jason Dion's practice exams on Udemy (3000+ questions)
Study 1 domain per week for 5 weeks, then 2 weeks of practice tests only
Score 85%+ consistently on practice tests before booking the real exam
Book through Pearson VUE — about $392 USD (check for vouchers on Reddit first)
professormesser.com Udemy: Jason Dion r/CompTIA on Reddit
✓
06.2
Pursue OSCP (The Offensive Gold Standard)
▼
OSCP (Offensive Security Certified Professional) is the most respected hands-on pentesting certification. It's a 24-hour hacking exam — break into machines or fail. No multiple choice. This is the cert that opens doors.
Preparation Path (3–6 months):
Complete TryHackMe "Jr Penetration Tester" path first
Complete 50+ HackTheBox machines (focus on easy/medium Linux and Windows)
Complete TCM Security's "Practical Ethical Hacking" course (affordable, excellent)
Do TCM's free Buffer Overflow prep on TryHackMe
When ready: purchase OffSec PEN-200 course + exam ($1499 or $99/month subscription)
During lab time: document EVERY machine in detail — your notes are your exam prep
HackTheBox.com TCM Security Course OffSec PEN-200
REALITY CHECK: OSCP has a high fail rate on first attempt. That's OK. The preparation alone makes you a professional pentester. Buy the course when you're consistently rooting HackTheBox medium machines.
✓
06.3

▼
Certs prove you passed a test. Your portfolio proves you can do the work. In cybersecurity, what you've built and broken matters more than your degree.

07.1
Active Directory & Enterprise Attacks
▼
95% of Fortune 500 companies run Active Directory. Owning AD = owning the company. This is advanced pentesting that requires deep knowledge of Windows internals.
Master:
Build an AD lab: Windows Server 2019 (domain controller) + 2 Windows 10 clients
Kerberoasting: request service tickets for crackable service accounts
Pass-the-Hash and Pass-the-Ticket attacks with Impacket tools
BloodHound: map AD relationships to find privilege escalation paths visually
DCSync attack: dump all domain hashes without being on the DC
Course: "Practical Active Directory" by TCM Security
TCM: Practical AD BloodHound / SharpHound github.com/SecureAuthCorp/impacket
✓
07.2
Cloud Security (AWS / Azure)
▼
The world has moved to cloud. Cloud misconfigurations are the #1 cause of data breaches today. Cloud security is one of the highest-paying niches.
Learn:
AWS Free Tier — spin up EC2, S3, IAM, Lambda. Understand the shared responsibility model
CloudGoat (Rhino Security Labs) — a deliberately vulnerable AWS environment to hack
SSRF → IMDSv1 → credential theft attack path (the classic cloud attack chain)
Tools: ScoutSuite, Pacu, Prowler for AWS security auditing
Certifications: AWS Security Specialty or Microsoft SC-900 → AZ-500
CloudGoat (Rhino Security) flaws.cloud (free AWS challenge) AWS Free Tier
✓
07.3
Build your reputation in the community
▼
The cybersecurity community runs on reputation. The best jobs don't get posted — they go to people who are known. Speak at conferences, publish research, mentor others.
How To Get Known:
Speak at a local BSides conference (beginner-friendly, free to attend, ~$0 to speak)
Write a technical blog post about something you learned the hard way
Release a security tool on GitHub and post about it on Twitter/X and LinkedIn
Find and report a CVE — even a minor one adds credibility permanently
Mentor one person newer than you on TryHackMe Discord or Reddit r/cybersecurity
BSidesconf.org DEF CON (Las Vegas annually) Twitter/X #infosec community
TRUTH: The people who rise fastest in cybersecurity are not always the best hackers. They are the ones who share the most, teach the most, and show up consistently. Be that person.
