eBPF — Extended Berkeley Packet Filter
What it is: Run sandboxed programs inside the Linux kernel without changing kernel source. Hooks into kprobes, tracepoints, XDP, cgroups.
bpftrace — high-level tracing language. One-liners for deep kernel visibility.
Cilium — eBPF-based K8s networking. Replaces iptables entirely. 3x faster than kube-proxy.
Falco — uses eBPF kernel module to intercept syscalls. Runtime security at kernel level.
BPFTRACE — ADVANCED KERNEL TRACING
# Trace all sys_execve calls (every command run) bpftrace -e 'tracepoint:syscalls:sys_enter_execve { printf("%s %s\n", comm, str(args->filename)); }' # Trace TCP connections with latency bpftrace -e 'kretprobe:tcp_connect { @[comm] = count(); }' # Find slow disk I/O (>10ms) bpftrace -e 'kprobe:blk_account_io_start { @start[arg0] = nsecs; } kprobe:blk_account_io_done /@start[arg0]/ { $lat = (nsecs - @start[arg0]) / 1000000; if ($lat > 10) { printf("slow I/O %d ms\n", $lat); } delete(@start[arg0]); }' # Count kernel function calls per process bpftrace -e 'kprobe:vfs_read { @[comm, pid] = count(); } END { print(@); }' # Trace OOM killer events bpftrace -e 'kprobe:oom_kill_process { printf("OOM kill: %s PID %d\n", comm, pid); }'

Kubernetes Request Lifecycle — Full Flow
1. kubectl apply — serializes object to JSON, sends to API server via HTTPS
2. Authentication — x509 certs / OIDC token / ServiceAccount JWT verified
3. Authorization (RBAC) — does this identity have permission for this verb+resource?
4. Mutating Webhooks — your admission webhooks modify the object (inject sidecars, add labels)
5. Object Validation — schema validation, default values applied
6. Validating Webhooks — OPA Gatekeeper, Kyverno reject or approve
7. Persist to etcd — object written with ResourceVersion
8. Scheduler watches — sees unscheduled pod, scores nodes, binds pod to node
9. kubelet watches — sees pod bound to its node, calls CRI (containerd) to start containers
10. CNI plugin — Cilium attaches eBPF programs, sets up pod networking via VXLAN/BGP

Observability — SLO Engineering
SRE LEVEL
"Define, measure and enforce SLOs with error budgets and automated burn-rate alerts"
📊
SLI → SLO → Error Budget → Burn Rate Alerts
SLI (metric)The raw measurement. E.g. "ratio of requests returning 200 in <500ms". Must be directly observable from your system.
SLO (target)"99.9% of requests succeed over 30 days". Your reliability promise. Too high = unsustainable cost. Too low = users unhappy.
Error Budget100% - SLO = budget for failures. 99.9% SLO = 43.2 min/month allowed downtime. Burn this for deploys, experiments.
Burn RateHow fast you're consuming error budget. Burn rate 1 = exactly consuming at SLO rate. Burn rate 14 = budget exhausts in 2h.
Alert policyAlert when burn rate >14x (1h window) AND >1x (6h window) — catches fast burns without alert fatigue on slow burns.

Incident Management — Production Playbook
Detect — Alert fires (burn rate >14x). On-call paged via PagerDuty. Acknowledge within 5 min SLA.
Triage — Open incident channel #inc-YYYY-MM-DD. Assign IC (Incident Commander) and comms lead. Declare severity (P0-P4).
Investigate — USE method: Utilization → Saturation → Errors. Check dashboards → traces → logs → recent deploys.
Mitigate first — Rollback deploy / feature flag off / scale up / fail over. Fix the customer experience BEFORE finding root cause.
Root cause — 5 Whys. Timeline reconstruction. Never blame people — blame systems.

Distributed Systems Patterns
Saga PatternLong-running distributed transactions without 2PC. Choreography (events) or Orchestration (central coordinator). Compensating transactions for rollback.
CQRSCommand Query Responsibility Segregation. Separate write model (commands) from read model (queries). Read replicas optimized per use case.
Event SourcingStore events, not state. Current state = replay of events. Audit log for free. Rebuild any projection. Kafka as event store.
Outbox PatternWrite to DB + outbox table atomically. Debezium CDC reads outbox, publishes to Kafka. Guarantees exactly-once event publishing.
BackpressureProducer slows down when consumer is overwhelmed. Kafka consumer lag triggers autoscale. Circuit breaker rejects when queue full.
Consistent HashingAdd/remove cache nodes with minimal key remapping. Used by Redis Cluster, Cassandra, DynamoDB. Ring with virtual nodes.
